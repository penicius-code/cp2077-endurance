# Changelog

1.0.0 to 1.2.0 were built on game version 2.31; from 1.3.0 the mod is for 2.5 and Dark Future 3.0. No version has a written in-game test record.

## 1.3.1 - 2026-11-23
### Fixed
- A save made under 25 % oxygen no longer loads with the heavy-breathing sway stuck on.

Not run in game.

## 1.3.0 - 2026-11-17
### Changed
- Port to game version 2.5 and Dark Future 3.0.
- The low-oxygen sway applies to both hands.

## 1.2.0 - 2026-11-06
### Added
- Chest injuries from the Injuries mod lower the oxygen capacity (tier 1 -10 %, tier 2 -20 %, tier 3 -35 %).

## 1.1.0 - 2026-11-02
### Added
- Event log ("Log" setting).

## 1.0.1 - before 2026-11-02
### Changed
- Plain-text descriptions for eight Dark Future status effects.

## 1.0.0 - before 2026-11-02
- First version: the oxygen reserve and its bar.
